# Implementation progress

Progress is measured from checked tasks in the Implementation order section of `doc/guide.md`. Requirements applied throughout, journey acceptance, and delivery-documentation checklists are excluded from this calculation. They remain separate release conditions, including browser and keyboard validation.

| Milestone                                   | Completed implementation tasks | Checklist completion |
| ------------------------------------------- | ------------------------------ | -------------------- |
| Diagnostic results, before concept learning | 36 / 65                        | 55.4%                |
| Concept learning and library                | 40 / 65                        | 61.5%                |

This counts tasks equally. It is not an estimate of remaining engineering time, production readiness, or commercial readiness. A checkbox for a small UI state and a checkbox for real authentication have very different effort. Backend accounts, email, live AI, fresh targeted practice, full progress/revision/settings, and release validation still require work.

The current local demo has home, simulated account entry, onboarding, dashboard, a saved diagnostic, detailed results, and concept lessons/library. Lessons connect to learning gaps; the fresh-practice part of the full learning loop remains next. Update the calculation from the guide whenever scope or task completion changes rather than treating this percentage as fixed.
